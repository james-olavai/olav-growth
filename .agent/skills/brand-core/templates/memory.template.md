## 4. Platform Blacklist & Anti-Ban Lessons (避坑与风控实录)
> 平台规则红线与历史封禁教训（永久避免触发）：
- **小红书/微信**：首发私信绝对不能直接发微信号或带二维码的图片，必须通过合规落地页或白名单暗号中转。
- **Reddit**：严禁在 `r/programming` 等技术主版面单开发布贴，必须在 Show & Tell 或周常主题下以纯干货形式回答。
- **LinkedIn**：加好友申请严禁附带长篇推销话术，空申请通过率反而高出 30%。
