# Pinterest 原生图文 (Standard Pin) 创作指南

> **与小红书复用关系**：
> 小红书最初的灵感即源自 Pinterest。“视觉信息图 (Infographic) + 搜索收藏”是两者的共同底层。
> 小红书的 3:4 视觉卡片（尤其是封面大字报和步骤图）可以直接作为 Pinterest 的高转化 Pin 图发布。

---

## 1. 核心属性与差异
* **用户心态**：Pinterest 本质是一个**视觉搜索引擎 (Visual Search Engine)**，而非社交聊天平台。用户来这里是为了“规划下一步行动”或“收藏可执行方案”。
* **最大优势（与小红书/IG 最大的不同）**：
  - **直接外链**：每个 Pin 图都可以直接挂载可点击的 **Destination URL**（直接引流到你的官网、博客文章或 Landing Page），完全不需要通过私信对暗号迂回！
  - **长效复利 (Long-tail Evergreen)**：一个优质 Pin 在发布 6 个月甚至 1 年后依然能在搜索结果中持续带来被动点击。

## 2. 视觉素材复用方式
* **直接使用 3:4 卡片**：
  - Pinterest 官方标准画幅为 2:3 (1000×1500) 或 3:4 (1080×1440)。
  - 小红书制作的 3:4 封面大字报或长图，完美契合 Pinterest 瀑布流（竖图在 Pinterest 浏览占比超 85%）。
* **卡片设计要点**：
  - 必须有清晰、大字号的文本覆盖 (Text Overlay)：“How to [Goal] in 3 Steps”。
  - 品牌 Logo 或官网域名建议放在顶部或底部安全区。

## 3. 标题与描述规范 (SEO 导向)
* **Pin Title (100 字内)**：纯搜索意图词堆叠，例如："AI Content Workflow: Step-by-Step Guide for Creators"。
* **Pin Description (500 字内)**：
  - 前两句直接写明解决方案与核心收获。
  - 自然融入长尾关键词（例如："Save time on social media scheduling with this automated pipeline. Includes free checklist."）。
* **Destination Link**：必须填写真实落地页，确保点击后直接跳转到提供该承诺价值的页面。
