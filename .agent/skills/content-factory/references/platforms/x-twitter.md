# X (Twitter) 短帖与 Threads 指南

## 1. 用户心态与语调
* **心态**：业内实时前沿、极客与早期采用者、公开记录。
* **Voice**：极度精炼、敏锐洞察、Build in Public（公开构建，分享进展与试错）。

## 2. 容器与格式
1. **Single Post**：
   - 1 句强刺激性观点或数据，直接配图（16:9 或 3:4 居中大图）。
2. **Threads 结构**：
   - 1/ 主楼：强 Hook + 承诺（“Here's the exact setup:”）。
   - 2-5/ 楼：每楼一个关键论据或代码/架构截图。
   - 尾楼：总结 + CTA（“If you found this useful, RT the first tweet & follow @me for more.”）。
