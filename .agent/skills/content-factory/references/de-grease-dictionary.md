# De-grease Dictionary: 去油去爹味人话词典

> 大语言模型天生倾向于生成“正确但平庸的废话”（公文腔、爹味商业套话）。
> 本词典提供强校验规则，指导 AI 如何从“机器公文”转向“素人真实人话”。

---

## 1. 禁用套话对照转换表 (Chinese)

| 🚫 机器爹味套话 | ✅ 人话素人表达 |
| :--- | :--- |
| **“为企业全面赋能”** | “帮团队少走弯路 / 每天省下 1 小时手工活” |
| **“提供一站式全方位解决方案”** | “把散落在 3 个工具里的事合在一个界面搞定” |
| **“助您扬帆起航，开启崭新篇章”** | “今天把这套从0到1的跑通步骤全盘托出” |
| **“在充满挑战与机遇的当今时代”** | “这两天和几个同行朋友复盘交流时发现...” |
| **“毋庸置疑 / 显而易见 / 众所周知”** | （直接删除，用具体的真实数据或案例开头） |
| **“引领行业创新的颠覆性产品”** | “我们自己用了两个月，发现解决了一个长期恶心人的小痛点” |
| **“为您保驾护航”** | “防止大家踩我之前踩过的坑” |

## 2. Banned AI Patterns (English)

| 🚫 Typical AI Buzzwords | ✅ Human & Direct Phrasing |
| :--- | :--- |
| **"Delve into the nuances"** | "Let's look at how this works" |
| **"In today's fast-paced world"** | "Last week when we were building [X]..." |
| **"A testament to innovation"** | "Here is the benchmark data:" |
| **"Revolutionize / Game-changer"** | "Makes [task] 3x faster without breaking [Y]" |
| **"Seamlessly integrate"** | "Connects with 1 single command" |

## 3. 语言瑕疵感准则 (Human Flaw Principles)

1. **第一人称视角**：永远使用“我”或“我们”，不要使用虚无的“本团队”、“广大用户”。
2. **坦诚说缺点**：主动提及产品目前不支持什么、适合什么阶段、不适合什么人群。越诚实，信任感越强。
3. **注入适度口语垫词 (Fuzzy Variables)**：
   - “说实话”、“讲真”、“其实底层原因很简单”、“踩过坑才明白”。
4. **长短句交错**：
   - 避免每句话都是 30 个字的复合长句。
   - 善用短句（例如：“结果呢？翻车了。” “为什么？很简单。”）。
