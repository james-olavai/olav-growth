# V2EX 社区发布指南

发布指南与浏览器操作流程。

---

## 发布节点与规则

* **目标节点**：`/go/create` (分享创造) 或 `/go/devops`
* **账号状态**：需已登录可用账号（V2EX 铜币需大于 20）。
* **格式要求**：V2EX Markdown 语法。

---

## 浏览器自动化流程

1. 使用 `navigate_page` 访问 `https://v2ex.com/new`。
2. 在节点选择框中选择 `分享创造`（节点代码 `create`）。
3. 填入 `v2ex.md` 中的标题（确保包含 `[分享创造]` 标识）。
4. 填入 `v2ex.md` 中的 Markdown 正文（包含开源声明、极简 60 秒体验、7 层安全保护及 GitHub 链接）。
5. 截取填表状态截图，确认无误。

> [!IMPORTANT]
> **发布策略**：国内社区默认保持草稿/填表预览状态，提请管理员人工复核后点击提交。
