# NetBox Community & Slack Reference Guide

Instructions for posting to NetBox Slack and NetBox Discourse.

---

## 1. NetBox Slack Channel Guidelines

### Target Channels
- **`#show-and-tell`** — Main approved channel for community project sharing.
- **`#integrations`** — Approved channel for API/integration tools.

> [!CAUTION]
> **NEVER post in `#general` or `#help`**. Self-promotion in main channels is prohibited and will cause messages to be flagged.

### Posting Workflow
1. Open NetBox Slack workspace.
2. Navigate to `#show-and-tell`.
3. Paste content from `olav-post/archive/YYYY-MM-DD/netbox-community.md`.
4. Ensure the **Open-Source Card** opening is intact (*"Hi everyone, I'm the maintainer of OLAV..."*).
5. Attach or link terminal demo gif / images.
6. Submit and monitor for community questions.

---

## 2. NetBox Discourse Forum Guidelines

### Target Category
- **`Community Projects`**

### Posting Workflow
1. Go to `forum.netbox.dev` (or NetBox Discourse).
2. Create New Topic in **Community Projects**.
3. Title format: `[Open Source] OLAV: Single-command natural language querying for NetBox`.
4. Paste formatted markdown content.
5. Add tags: `netbox`, `ai`, `automation`, `python`.
