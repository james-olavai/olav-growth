# Video Runsheet & Alignment Guide

Guidelines for creating video demo runsheets, SSH execution timing, and TTS subtitle alignment.

---

## Runsheet Markdown Structure

Every `video-runsheet.md` generated by `content-writer` must follow this structure:

```markdown
# Video Runsheet — [Title]
**Date**: YYYY-MM-DD
**Topic**: [Primary Campaign Focus]

---

### Beat 1 — [Short Beat Title]

**[Command]**:
```bash
olav registry register http://netbox:8000
```

**[Voiceover]**:
> "Welcome to OLAV. Connecting your NetBox instance takes just a single command with zero MCP server overhead."

**[Target Subtitle]**:
Welcome to OLAV. Connecting your NetBox instance takes just a single command with zero MCP server overhead.
```

---

## Time Alignment Algorithm

The alignment script (`verify_and_align_runsheet.py`) calculates the exact timestamp for each Beat:

1. **`T_cmd`**: Real command execution duration via SSH / local sandbox execution.
2. **`T_user_pad`**: Estimated manual typing / UI navigation buffer (default: 4.0 seconds).
3. **`T_voice`**: Audio duration of generated TTS voiceover.
4. **`Step_Duration`**: `max(T_cmd + T_user_pad, T_voice + 1.0)`

This guarantees that the user has enough time to type on screen while ensuring the TTS narration and SRT subtitles align seamlessly without clipping!
